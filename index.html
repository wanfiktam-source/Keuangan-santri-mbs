Pengaturan Cloud Sync Real-Time

Status Koneksi Saat Ini: Mode Lokal (Offline)

Gunakan Firebase Realtime Database (Gratis) agar data tersinkronisasi otomatis antar HP Pengurus, Tablet, dan Laptop Bendahara secara real-time.

Semua perangkat dengan ID Ruang & Firebase yang sama akan melihat dan mengedit data yang sama.

Cara Mendapatkan Firebase Config Gratis (2 Menit)
  1. Buka console.firebase.google.com lalu buat project baru (gratis).
  2. Pilih menu Build → Realtime Database → Create Database, pilih lokasi (misal Singapore) dan mulai dalam Test Mode.
  3. Salin URL database (`https://...firebasedatabase.app`).
  4. Buka Project Settings (ikon gerigi) → General → Your apps → Web (</>), daftarkan aplikasi, lalu salin blok kode firebaseConfig dan tempel di kotak atas.
